# Contributing Guide

Thank you for contributing.

## Principles

- Keep examples correct and minimal.
- Prefer modern C++ (C++17+ unless a section explicitly targets older standards).
- Maintain consistent formatting and explanatory comments.

## Content Updates

When updating `docs/STL_GUIDE.md`:

1. Ensure code snippets compile independently when they include `main()`.
2. Keep section titles clear and consistent.
3. Mention required headers for each topic.
4. Avoid duplicate or contradictory explanations.

## Pull Request Checklist

- [ ] Changes are focused and readable.
- [ ] Markdown renders correctly.
- [ ] Any example snippet added has been locally compiled (where applicable).
- [ ] README links and paths are valid.
